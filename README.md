SenimdiTruck
Сенімді жүк тасымалдау төлемдері — блокчейн арқылы.
Мәселе
Қазақстандағы жүк тасымалдау нарығында төлем алаяқтығы жиі кездеседі: не жүк
иесі жеткізілген жүк үшін төлемейді, не айдаушы алдын ала төлем алып, жүкті
жеткізбейді. Дәстүрлі шешімдер (банктік аккредитив, факторинг) баяу және
шағын/орта ойыншылар үшін қымбат.
Шешім
SenimdiTruck — жүк тасымалдау төлемдерін escrow (шартты сақтау)
механизмі арқылы қорғайтын Solana негізіндегі жоба:
Жүк иесі келісілген соманы смарт-контрактқа құлыптайды.
Айдаушы жүкті жеткізеді.
Жеткізу расталған соң (QR-код немесе екі тарап растауымен), ақша
автоматты түрде айдаушыға шығады.
Дау туындаса, тағайындалған төреші (arbiter) мәселені шешеді.
Айдаушылар мен жүк иелері үшін процесс толығымен таныс Telegram бот
интерфейсі арқылы жүреді — блокчейн, кошелек немесе крипто терминдерін
білудің қажеті жоқ.
